# Install — ChatGPT Project

Verified against OpenAI documentation on 2026-08-26.

## Setup

1. In ChatGPT, create a new Project.
2. Give it a name such as **Betaal: Justice**.
3. In Project settings, paste the contents of `PROJECT_INSTRUCTIONS.md` into Project Instructions.
4. Upload the files in `UPLOAD_MANIFEST.md`.
5. Add your lawful source material for the work.
6. Start a chat inside the Project or use Voice inside the Project.

## Portability

ChatGPT Projects are designed to keep project chats, files, and instructions together and can be continued across supported devices on the same account. Projects can also be shared; current sharing options include invited users and, where available, “Anyone with a link” for logged-in users.

For a shared experiment, remember that shared projects use project-only memory and members can see project chats/files according to their access.
