# *Justice* — Sources and Grounding

## Primary source

**Michael J. Sandel, *Justice: What's the Right Thing to Do?***

This repository deliberately does not contain the book text. Add a lawful copy, excerpts, highlights, or notes to the runtime when exact textual grounding is needed.

## Official / author-affiliated enrichment

- Harvard / Sandel Justice material: https://sandel.scholars.harvard.edu/justice
- Harvard Online course page: https://harvardonline.harvard.edu/course/justice

These can help with lecture cases and broad framing, but the user's chosen edition of the book remains the authority for book-specific claims.

## Grounding protocol

When answering a close-reading question:

1. Search/retrieve the relevant primary text if available.
2. Separate what the text says from interpretation.
3. If a claim depends on edition-specific page numbering, cite the edition or avoid the page number.
4. Do not manufacture quotations from memory.
5. If the exact passage is unavailable, say what can be discussed confidently at the argument level and what needs checking.
