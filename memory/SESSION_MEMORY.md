## Memory rules

1. Save claims the user actually made; do not infer sensitive traits or ideology.
2. Preserve uncertainty: “wondering whether X” is different from “believes X.”
3. Prefer ideas likely to become useful later in the same work.
4. When a position changes, retain enough of the old position to make the development legible.
5. Avoid storing incidental personal details unless the user explicitly wants them connected to the discussion.
